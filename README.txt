This folder is where your two required screenshots go.

Steps to generate them:
1. Compile:   javac Student.java Main.java
2. Run:       java Main
3. Take a screenshot after choosing option 1 and entering a new student's
   info -> save as add_object_demo.png (or add_student_demo.png)
4. Take a screenshot after choosing option 2 to list all students
   (including the new one you just added) -> save as list_output.png
5. Delete this README once your two screenshots are in place (optional).

Then from your project root:
    git add .
    git commit -m "added menu and list function for Student tracker"
    git push
